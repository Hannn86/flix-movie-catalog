# 🎬 FLIX Movie Catalog

Website katalog film yang menggunakan TMDB API untuk menampilkan informasi film secara dinamis.

## 📌 Tentang Project

FLIX Movie Catalog adalah website katalog film yang memungkinkan pengguna melihat berbagai informasi film seperti film populer, sedang tayang, rating tertinggi, dan film yang akan datang.

Data film diperoleh dari TMDB API.

## ✨ Fitur

- 🔥 Film Populer
- 🎬 Film Sedang Tayang
- ⭐ Film dengan Rating Tertinggi
- 📅 Film Segera Hadir
- 🔎 Pencarian Film
- 🎭 Filter berdasarkan Genre
- 📖 Melihat detail dan sinopsis film
- ⭐ Menampilkan rating film
- 🖼️ Poster dan backdrop film
- 🔄 Pagination
- 🎞️ Hero/banner film

## 🛠️ Teknologi

- HTML
- CSS
- JavaScript
- Python
- TMDB API
- SQLite
